# Eggnog/emapper

Version: https://conda.anaconda.org/bioconda/noarch/eggnog-mapper-2.1.15-pyhdfd78af_0.conda

Update annotations from *Culex tarsalis* assembly (Main et al.) in order to map IDs (e.g. geneXXXX) to *Culex quinquefasciatis*, which has some functional annotations.

- download *Culex tarsalis* protein/gene annotations from Main et al.
- 
Run on Alpine cluster.
