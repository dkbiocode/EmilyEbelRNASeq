## Data files

|filename | description | details |
|-------- | ----------- | ---- |
| EG\_all\_results\_table\_DCK.tsv | Long format data table of all genes tested in all comparisons | full statistic output per row | 
| EG\_all\_results\_table\_DCK\_noMT.tsv | As above excluding genes with "^MT-" in gene names. | full statistic output per row | 
| EG\_sig\_l2fc\_DCK.tsv | Log2Fold change in each cell. | "significant" genes only (0.1) |
| EG\_sig\_padj\_DCK.tsv | Adjusted p-value change in each cell | "significant" genes only (0.1) |
